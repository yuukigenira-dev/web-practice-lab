# web-practice-lab

HTML・CSS・JavaScript・jQueryを、解説・クイズ・操作できるデモで復習するWeb学習アプリ。レスポンシブデザインの学習にも対応。

## アプリを開く

https://yuukigenira-dev.github.io/web-practice-lab/

## 現在のバージョン

- v4（2026年11月18日更新）
- 95単元・168問
- レスポンシブデザインの追加教材と、幅を変えて試せる10種類のデモを収録

## 使い方

公開URLを開いて学習できます。`index.html`をダウンロードして、ブラウザで開いても利用できます。

学習記録は、使用中の端末・ブラウザに保存されます。端末間では自動同期されません。端末やブラウザを変えるときは、アプリのJSON書き出し・読み込み機能で記録を移してください。

## 更新方法

`main`ブランチのルートにある`index.html`を最新版で置き換えます。GitHub Pagesは`main`の`/ (root)`を公開元に設定します。バージョン番号はアプリ内で管理し、公開URLは固定します。
